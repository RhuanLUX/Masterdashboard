# Referências técnicas de temas — RPG Master V2.2

O sistema de temas deste projeto é uma implementação própria, local e sem
dependências de runtime. Nenhum arquivo, script ou asset de terceiros foi
copiado para este repositório.

Foram avaliadas como referências técnicas:

- [Alphaproject1998/snow-fx](https://github.com/Alphaproject1998/snow-fx) —
  canvas de neve com camadas, pausa por visibilidade e redução de movimento;
  licença MIT.
- [DMS-Menula/spooky-portal](https://github.com/DMS-Menula/spooky-portal) —
  referência visual para névoa, morcegos e atmosfera de horror; licença MIT.

As ideias gerais de baixo custo (um canvas para partículas, animações CSS
discretas e respeito a movimento reduzido) foram reimplementadas do zero para
se adequar à arquitetura offline do RPG Master. Não há obrigação de aviso de
copyright desses projetos porque nenhum código ou asset deles foi reutilizado.
